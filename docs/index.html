Comparing Internal Validation Methods for Clinical Risk Prediction

A Simulation Study

Author

Ashley Dickson

Published

January 10, 2026

1 Overview

This simulation study compares three internal validation methods (sample splitting, cross-validation, and bootstrap) for clinical prediction models using 500 simulations with realistic sample sizes (n=858).

2 Background

Clinical prediction models often perform poortly in new patients compared to development data due to overfitting. Internal validation provides realistic performance estimates without requiring external datasets. This study compares sample splitting, 10-fold cross-validation, and bootstrap optimism correction against external validation across discrimination, calibration, and overall accuracy metrics. It then compares external validation data set sizes to asymptotic ‘truth’.

3 Methods

3.1 Data Generating Process

Simulated scenario: - Binary outcome with 15% prevalence - 10 continuous predictors (X₁…X₁₀), all ~N(0,1) - Logistic regression with mixed effect sizes - Intercept (α = -1.9665) calculated to achieve exactly 15% prevalence

Model equation:

\[ \text{logit}(P(\text{outcome}=1)) = -1.9665 + 0.45X_1 + 0.40X_2 - 0.35X_3 + ... + 0.05X_{10} \]

3.2 Sample Sizes

  • Development: n=858 (129 events, EPV=12.9)
    • Determined using samplesizedev package
  • External validation: n=100,000
  • Simulations: 500 iterations

3.3 Methods Compared

For each simulation:

  1. Apparent validation - Optimistic test on development data (baseline)
  2. Sample Split - 70/30 split
  3. 10-fold Cross-validation - Stratified folds with pooled predictions
  4. Bootstrap - Harrell’s optimism correction (200 resamples)
  5. External validation - Independent large dataset

3.4 Performance Metrics

  • Discrimination: AUC (C-statistic). The true model has a C-statistic of 0.704.
  • Calibration: Calibration slope (1.0 = perfect; <1.0 = overfitting)
  • Overall accuracy: Brier score, Mean Absolute Prediction Error (MAPE)

External calibration slopes are computed using the same fitted models used for internal validation (bootstrap refits, CV fold models, and sample-split training models). For calibration slope, CV and bootstrap internal estimates are averaged across their fold/refit models to align with the external calculation. The earlier mismatch that compared refit-based internal slopes to a single full-model external slope is not used in this analysis.

5 External Validation Sample Size Requirements

While internal validation methods help estimate model performance on the development data, external validation on independent data sets provide an honest test of a model’s capacity to generalise. However, a key question remains: how large should an external validation data set be?

This section examines the relationship between external validation sample size and performance estimate stability, using models trained on the Pavlou-recommended sample size (n=858).

5.1 Methods

For each of 1000 simulations:

  1. Generate training data (n=858, following Pavlou’s sample size recommendation)
  2. Fit a logistic regression model on the training data
  3. Validate the model on external datasets of varying sizes:
    • n = 858, 1716, 3432, 6864, 13728, 27456, 54912, 1e+05
  4. Calculate performance metrics (AUC, calibration slope, Brier score, MAPE) for each validation size

This design isolates the effect of validation sample size on performance estimate variability and correlation with the asymptotic ‘truth’ (n=100,000).

5.4 External Validation Results

Calibration slope and MAPE achieve correlation = 0.9 somewhere between 4x and 6x the training size, while AUC requires 12x to achieve 83.5%. Brier Score never exceeds 0.5 correlation, even at 12x. Calibration, AUC and MAPE yield substantial improvements in variability with increasing validation sizes, while the Brier Score’s variability hardly changes. Across the board, the marginal gain in precision diminishes substantially beyond ~10× the training size.
